# 规整文档

本仓库禁止在子目录散落 `README.md`，全部文档集中在 `doc/`。本文档是阅读入口与文档索引。

## 阅读顺序

1. [架构设计](架构设计.md)：分层、生命周期、能力分组、新增适配端的约束。
2. [状态与锁规范](状态与锁规范.md)：统一运行状态表与命名锁的使用规则。
3. [数据库边界](数据库边界.md)：适配层持久化的读写边界、单写队列与缓存要求。
4. [S4A21 能力状态](S4A21能力状态.md)：当前适配端能力矩阵；增删能力时必须与 `internal/composition/backend/s4a21/descriptor.go` 同步。
5. [构建与发布](构建与发布.md)：本地验证、构建脚本、Windows/Linux 平台说明与安全部署前提。
6. [新增适配端](新增适配端.md)：复制适配层的操作步骤。

## 仓库根目录文档

- `AGENTS.md`：执行约束（分层、生命周期、锁、状态表、数据库边界、禁止恢复原生服务端代码等）。

## 变更规则

- 文档描述必须与代码事实一致；发现不一致时先修文档或代码，再补充说明。
- 能力状态只描述已实现且已完成的验证，不把"仅编译通过"记作"已验证"。
- 运行时产物（日志、缓存、导出 JSON）不进入仓库。
