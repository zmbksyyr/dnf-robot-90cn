# 构建与发布

项目使用单进程 Robot，Web、调度器和适配器在同一生命周期内运行。

## 本地验证

```text
go test ./...
go vet ./...
go build ./cmd/robot
git diff --check
```

## Windows

使用 `deploy/build-robot.bat` 生成 Windows amd64 Robot。当前 S4A21 发布包只支持 Windows；生成物只放在 deploy 输出目录，不提交到仓库。配置、日志和运行时目录由程序首次初始化时按适配器能力生成。

构建前确认没有释放原生密钥、原生服务配置、市场/邮件配置或其他当前适配端不支持的文件。
