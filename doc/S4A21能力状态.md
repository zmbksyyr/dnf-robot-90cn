# S4A21 能力状态

本文档记录当前仓库对应的 S4A21 模拟端能力边界。状态只描述本仓库已经实现的代码和已完成的验证，不代表服务端本身具备同名功能。

## 已实现并验证

- Robot 初始化、角色发现、角色认领和目标在线人数调度。
- 假人登录、保活、退出和重连。
- 城镇坐标解析、城镇移动和区域切换。
- 普通喊话/区域喊话，以及喊话模板和间隔调度。
- 角色删除、清理和 Robot 账号/角色身份维护。
- 角色等级、名字模板、职业与性别匹配。
- 装备、左右槽、装扮、宠物和宠物装备的生成与持久化。
- 尽量成套、尽量多样、按职业过滤的装备和装扮穿戴逻辑。
- 真人邀请假人入队，假人自动接受邀请。
- 假人在城镇中跟随队长移动。
- 队伍状态变化、真人退出或踢出后，假人退出跟随并恢复普通调度。
- Web 配置、调度、可见角色选择操作和 SQLite 只读统计审计。

## 已实现但不完整

- 工会邀请自动同意已实现，并已接入 S4A21 包解析；工会完整管理、主动申请、退出和更多事件处理尚未覆盖。
- 组队跟随已实现为“跟随真人队长”模式；假人主动建队、主动邀请、战斗、技能、房间切换、结算和回城不在当前范围内。
- 地下城跟随只处理服务端/队伍投影带来的跟随状态，不实现主动寻找入口或主动进入下一个房间。
- 清理和危险删除已实现，但危险删除属于适配层 SQLite 操作，只针对明确的 Robot 身份，不用于普通调度缩容。

## 未实现或明确置空

- 拍卖行。
- 金币寄售。
- 摆摊和副职业交易行为。
- 邮件通知轮询。
- 系统公告传输。
- 世界喊话/喇叭；当前使用普通区域喊话。
- 主动地下城移动、技能释放、战斗、战斗结算和回城。
- S4A21 专用诊断、服务控制和 party debug。

上述能力必须通过适配器返回明确的 unsupported 结果，Web 页面应隐藏或置灰，不能由公共调度层伪造成功。

## 尚未验证

- Linux 环境下的完整实机运行周期：初始化、PVF/SQLite 读取、登录调度、组队跟随、停止和再次初始化。
- Linux 下实际 S4A21 服务端地址、端口和数据库路径组合。
- Windows/Linux 长时间高在线人数运行下的连接稳定性和资源上限。

Windows 和 Linux amd64 仅表示构建与交叉编译支持，不等同于 Linux 实机验证完成。

## 维护规则

- 新增或修复 S4A21 能力时，同步更新本文档和 `internal/composition/backend/s4a21/descriptor.go`。
- “已验证”必须有可复现的服务端/客户端验证记录；仅编译通过只能标记为“已实现”或“未验证”。
- 后续适配其他模拟端时复制适配层和对应能力文档，不得把 S4A21 的能力状态写入公共调度、Actor 或 Web 判断。
